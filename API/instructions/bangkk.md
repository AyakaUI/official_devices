# Install AyakaUI on Moto G84 5G (bangkk)

## Clean Flash
- 1 fastboot flash boot boot.img
- 2 fastboot flash vendor_boot vendor_boot.img
- 3 Go to Recovery Ayaka
- 4 sideload + Ayaka*.zip
- 5 formata data
- 6 reboot.


# Dirty Flash
- 1 sideload + Ayaka*.zip
- 2 reboot system.

# Ota Updater 
- 1 Install from Updater 
- 2 Reboot.
- 3 Done.
